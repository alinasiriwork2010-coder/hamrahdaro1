همراه‌دارو — نسخه نمایشی v2
ویژگی‌های جدید:
- صفحه Splash با انیمیشن
- صفحه ورود نمایشی
- ورود با موبایل/رمز عبور به‌صورت کاملاً ساختگی
- ورود نمایشی با Google
- انیمیشن انتقال صفحات
- خروج نمایشی
- بدون Firebase، بدون دیتابیس و بدون ارسال اطلاعات

برای GitHub Pages:
1. فایل‌های index.html، style.css و script.js را در Repository قرار دهید.
2. Settings > Pages > Deploy from a branch
3. Branch = main و Folder = / (root)
4. Save

این نسخه صرفاً Demo است و برای ورود واقعی طراحی نشده است.
